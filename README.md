# knowledge-emotion-video

> 一套用来创作「知识 × 情绪」类短片的 Agent Skill：用一个精确的科学概念，给一种说不清的人生处境命名。

2 分 40 秒左右，深色仪器风，一个物理 / 数学 / 心理学概念解释一种生活经验。产出的不是文案，是**可执行的六幕结构 + 逐秒时间表 + 视听量化规范**，可以直接对接 canvas / three.js 渲染管线，也可以走 AI 生图生视频流程。

## 它解决什么问题

市面上大部分「知识短视频」失败在两个地方：

1. **选题不可指认**——开场那句抓不住人，因为观众 3 秒内想不起自己的一件事；
2. **画面和音乐各走各的**——画面很漂亮，但没有跟着重击走，看两分钟就平了。

这个 skill 把这两件事变成了可检验的判据：

```text
播放量 ≈ 母题的普适度 × 概念的意外度 × 场景的可指认性
```

三项缺一，成片就废。第三条是一票否决项。

## 核心规范（不满足就别发）

| 项 | 值 |
|---|---|
| 时长 | 160–170 秒 |
| 镜头平均长度 | ≥ 16 秒（靠镜头内运动，不靠快切） |
| 画面暗部（亮度<20） | ≥ 65% |
| 画面高光（亮度>200） | ≤ 1% |
| 字幕 | 44–48px / 字重 300 / 底部 91–96% |
| 关键词染色 | 每句只染 1 个词，琥珀金 |
| 暖色占比 | 冷色的 3 倍以上，全片只出现在 3–5 处 |
| 概念名出现 | 85 秒前 |
| 叙事高潮 | 90–110 秒 |
| 可复读钩子 | 每条至少 1 个，≤ 4 字 |

## 六幕结构

| 幕 | 时间 | 功能 |
|---|---|---|
| ① 悖论开场 | 0–15s | 一个说不通的事实，不解释 |
| ② 实验/史料 | 15–55s | 年份 + 人名 + 一个操作细节 |
| ③ 命名 | 55–85s | 给现象一个能被复述的名字 |
| ④ 私人化 | 85–115s | 三件具象小事并列，零形容词 |
| ⑤ 反转 | 115–145s | 重新评价这个「缺陷」——它是功能不是 bug |
| ⑥ 落款 | 145–164s | 升格观众，不总结知识点 |

## 让画面咬住音乐

判断「有没有冲击」**必须用 10 ms 窗口**。用 2 秒窗口量，会把 11.8 dB 的低频动态压成 4 dB，得出「没有起伏」的反结论。

`references/audio-sync.md` 给了完整的三步法：提取低频上升沿 → 按强度分三级 → 接到画面上。分级是必须的，不是优化——47 个重击点如果每个都做特效，第三个之后观众就麻木了。

`assets/impacts-yubo.json` 是从一条参考音轨（164 秒 / 146 BPM）算出来的 48 个冲击点，可以直接读进时间表。

## 关于素材

仓库包含两部分配套素材：

- `assets/ref-yubo-164s.m4a`——164 秒参考音轨（作者本人的作品，B 站「比特新语」《余波》，146 BPM）。可以直接用它跑通整套流程。
- `assets/impacts-yubo.json`——从这条音轨算出的 48 个冲击点 `[秒, 强度]`，可直接读进时间表。

换成自己的音轨时，重跑 `references/audio-sync.md` 里的检测代码即可，不需要手工标点。

## 方法论来源

这套规范来自对作者本人账号「比特新语」19 条投稿的全量拆解（2026-10，B 站，总播放 1927 万）：

- 逐条采集元数据、弹幕 6247 条、封面 19 张；
- 下载 5 条 1080P 原片逐帧抽检 + 字幕全量转录；
- 像素级色板统计（70.2% 的像素亮度低于 20，暖色占比是冷色的 3.2 倍）；
- 10 ms 窗口音频包络分析。

几条反直觉的实测结论：

- **点赞率与播放量相关性 −0.02**——质量轴和选题轴是两条独立的轴；
- **前 10 秒的弹幕峰值不是高潮**，是追更仪式（刷「万粉」），叙事高潮在 90–110 秒；
- **切点只有 4–10 个 / 164 秒**——它靠长镜头内运动，不靠快切。
