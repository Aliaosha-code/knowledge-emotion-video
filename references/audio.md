# 声音：一堵恒定的墙

## 一、实测特征

对 3 条视频做 2 秒窗口 RMS 包络分析：

| 指标 | 银牌 | 剃刀 | 余波 |
|---|---|---|---|
| 整体 RMS | −16.1 dB | −15.3 dB | −11.8 dB |
| 峰值 | −0.3 dBFS | −5.0 dBFS | 0.0 dBFS |
| 动态范围（p90−p10） | **4.7 dB** | **4.1 dB** | **4.3 dB** |
| 静默窗口（< −40dB） | 0% | 0% | 1% |

**结论：宏观是一条近水平的线，微观靠节拍脉冲撑住。**

2 秒窗口看，动态范围只有 4 dB——没有段落、没有副歌、没有长留白。但把窗口缩到节拍级，起伏有 12–15 dB（每下底鼓都是一次呼吸）。两者不矛盾：**宏观恒温，微观有脉搏**。

如果只做宏观平坦（一条直线响到底），听感是"糊"；如果只做微观脉冲而没有稳定的底层，听感是"散"。两层必须同时成立。

这个选择跟画面完全一致：**长镜头 + 恒定声墙 = 匀速沉浸**。整套片的策略是"把你按进一个恒温房间"，不是"用节奏刺激你"。

## 二、制作规范

| 项 | 值 |
|---|---|
| 速度 | **146 BPM**（《余波》实测，节拍格约 0.41s/拍） |
| 目标响度 | RMS **−15 ~ −16 dB**（实测样本 −11.8 ~ −16.1） |
| 峰值 | ≤ −1.0 dBFS（留一点余量，实测样本压到 −0.3 太紧） |
| 宏观动态（2s 窗口 p90−p10） | **4–6 dB** |
| 微观动态（节拍级） | **12–15 dB** |
| 静默段 | **不要有**。段落之间用低频铺底续着 |
| 声道 | 立体声，48kHz，AAC 192–256k |
| 频谱配比（参考） | sub 12% / bass 15% / mid 29% / hi 25% / air 18% |
| 频谱质心 | ≈ 3400–3700 Hz |

> 实测《余波》的 RMS −11.8 dB 明显高于其他两条（−15 ~ −16），属于母带偏响。统一到 −15.5 更稳。

## 三、层次结构

三层，从下往上：

1. **底层（恒定）**：低频 pad / 持续音，−30 dB 左右，全片不断。这是"房间的温度"。
2. **中层（事件）**：极简打击点、单音、颗粒质感，只在情绪拐点出现。
3. **顶层（旁白）**：人声，−12 ~ −15 dB 之间，始终清晰可辨。

旁白段落把 BGM 压到 −24 dB 以下；无旁白段落让底层浮上来 2–3 dB。**只有这一个动态，不要再加别的。**

## 四、推力来自侧链，不是音色

这类片子听起来"有劲"，九成归功于**侧链压缩**：每下底鼓把 pad / arp 压低（约 62%），15ms 恢复。

换音色、加失真、堆层数，效果都不如这一个动作。因为它制造的是"呼吸"——同一时刻有一个元素在让位，另一个在顶上来。

总线再加 15–20 个关键帧做整体起伏（全片 12–15 dB），重音落在**画面时间点**上，不量化到节拍格。画面切点比节拍重要：观众感知的是"音画同时发生"，不是"在第 41 拍"。

## 四、音效对齐的三个点

声音事件只在这三处打，多了就散：

| 位置 | 功能 | 音色 |
|---|---|---|
| **③ 命名**（55–85s） | 概念名出现的瞬间 | 一个干净的"落定"音：单音、铃、低频撞击 |
| **⑤ 反转**（115–145s） | "但先别急着…" 之后 | 反向音、滤波扫频、情绪翻转 |
| **⑥ 落款**（145–164s） | 最后一句 | 长尾混响，让声音散开 |

其余位置**只用画面运动带声音**，不要额外加音效。

## 五、与画面同步的做法

不要在音乐里硬编码秒数。做法（对应用户既有工程）：

1. 在时间表里声明 `SFX_CUES`：`{ t: 72.4, kind: 'naming', gain: -8 }`
2. 渲染前把 `SFX_CUES` 导出成 `cues.json`
3. 音频合成脚本读 `cues.json`，在对应采样点写入音效

这样改脚本时音效自动跟着走，不需要手抄时间。

## 六、合成器实现（numpy，无采样）

用户环境无 scipy，滤波走 FFT 掩码、混响走延迟叠加。

- **pad**：2–3 个正弦叠加 + 缓慢 LFO 调幅，加轻微失谐产生拍频
- **落定音**：指数衰减正弦（τ ≈ 0.8s）+ 少量二次谐波
- **反转音**：噪声经 FFT 带通，中心频率随时间上扫
- **混响**：3–5 个不同延迟的衰减副本叠加（Schroeder 简化版）

整体后处理：软削波（tanh）→ 归一化到目标 RMS → 峰值限制。

## 七、留白必须音画同时留

做《临界》时在 137.4s 做了一个反转：画面所有元素退成余烬、只剩一个点，音乐断崖抽空 17 dB。

把这套画面配上参考片《余波》的原版音轨试听，**这个设计被完全抵消了**——因为《余波》的音轨从 0 到 160 秒是一条几乎恒定的声墙（1 秒窗口包络全程满格，只有最后 5 秒退下去），画面再怎么收，观感还是"满"的。

结论：**画面的留白必须有声音同时让位，否则观众感知不到留白。**反过来也成立——配乐若是一条平铺的墙，画面再克制也换不来"静"。

判断方法：把 1 秒窗口的 RMS 包络画出来，和字幕区间叠在一张图上。如果音乐是满格而画面在该处收住了，说明这一处的设计是白做的。
