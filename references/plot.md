# 选题：母题 × 概念 × 可指认场景

## 一、母题库（按"人人都会遇到"排序）

选母题只有一条标准：**不需要任何身份前提**。学生、上班族、恋爱中的人、中年人，都得撞上。

| 母题 | 具体形态 | 已验证播放 |
|---|---|---|
| **差一点** | 差 3 秒的地铁、差 1 分的分数线、打好了又删掉的话 | 345 万 |
| **对方不回消息** | 三小时没回，脑子演了一百种解释 | 202 万 |
| **努力却没结果** | 全力奔跑却留在原地 | 35 万（概念硬，见下方警告） |
| **学习/考试焦虑** | 刷题满分却没学会 | 148 万 |
| **说不出口** | "我爱你"说到第 1000 遍 | 120 万 |
| **生活失控** | 房间不打扫会落灰，感情不管会变冷 | 84 万 |
| **选择困难** | 什么时候该定下来 | 89 万 |
| **吵架后的沉默** | 一句话的余震 | 87 万 |
| **怀旧/乡愁** | 每个文明都酿酒 | 50 万 |
| **上瘾** | 明明知道还停不下来 | 54 万 |

**母题越具体越好。** 不要写"孤独"，要写"凌晨三点想找人说话，翻完通讯录关掉手机"。

## 二、概念库（按"解释力/门槛"比排序）

挑概念的标准：**能解释一个日常现象，且不需要前置知识**。

### 甜点区（物理/自然现象，自带画面）
- 热力环流 → 两个一样的地方之间不会起风
- 熵增 → 房间会乱、感情会冷
- 引力波 → 一句话的余波
- 神经递质（多巴胺/皮质醇/血清素）→ 上瘾、拖延、焦虑
- 光遗传学 → 大脑的开关
- 中微子 → 最害羞的信使

### 好用区（数学/统计，需要一个动作演示）
- 最优停止（37% 法则）→ 什么时候该做决定
- 反事实思维 → 为什么"差一点"最痛
- 遍历性 / 期望效用陷阱 → 为什么不敢 all in
- 古德哈特定律 → 指标一变目标就失效
- 信息熵 → 重复的话没有信息
- 博弈论（以牙还牙/TFT）→ 怎么对待伤害过你的人

### 谨慎区（概念硬、受众窄，必须有强场景兜底）
- Scaling Law / 涌现 → AI 从业者才有的画面感（实测 37 万）
- 手性 / 对映异构 → 抽象（实测 32 万）
- 红皇后假说 → 母题好但概念绕（实测 35 万）

> 谨慎区不是不能做，是**必须在前 15 秒给一个极度具体的画面**。否则概念越精确，观众越早走。

## 三、配对方法

配对不是"找个比喻"，是**找结构同构**：科学现象的特征参数，恰好等于情绪经验的特征参数。

四类可复用的同构：

| 同构类型 | 科学侧 | 情绪侧 | 例 |
|---|---|---|---|
| **时间尺度错位** | 碰撞 0.2 秒，涟漪传 13 亿年 | 一句狠话 1 秒，记恨三年 | 余波 |
| **阈值/临界** | 37% 后不再观察 | 什么时候该定下来 | 37 法则 |
| **不可逆累积** | 熵只增不减 | 关系不维护必然变冷 | 熵增 |
| **反馈回路** | 你进化一步，对手环境恶化一步 | 内卷 | 红皇后 |

配对时问三个问题：
1. 这个现象里，**最反直觉的一个数**是什么？
2. 这个数在人生里，**对应的那个数**是什么？
3. 两个数放在同一句话里，**会不会让人愣一下**？

三个都"是"，配对成立。

## 四、可指认性检验（一票否决）

把开场第一句念给一个不在行业内的人听，问他："你上一次遇到这个，是什么时候？"

| 反应 | 判定 |
|---|---|
| 立刻说出一个具体时间地点 | ✅ 通过 |
| "嗯……好像有过" | ⚠️ 需要换更具体的场景 |
| "没太懂" / 沉默 | ❌ 否决，重做 |

**失败案例复盘**

| 开场原句 | 问题 | 结果 |
|---|---|---|
| "20 岁手里只有一样东西，你把它扔给谁了？" | 抽象动作，无场景 | 22 万 |
| "把一句话最后一个字遮住，让模型猜" | 需要 AI 知识才有画面 | 37 万 |
| "你不是不理性，你只是只有一次人生" | 抽象指控，观众不认领 | 11 万 |

**成功案例对照**

| 开场原句 | 为什么有效 | 结果 |
|---|---|---|
| "领奖台上，第二名笑不出来。第三名，却笑得像赢了。" | 人人见过的画面 + 反差 | 345 万 |
| "他三个小时，没回消息。" | 一句话就是一个完整场景 | 202 万 |
| "房间不打扫，就会落满灰。" | 身体记忆 | 84 万 |
| "13 亿年前，两个黑洞撞在了一起。" | 奇观 + 后面会接到自己 | 87 万 |

## 五、标题结构

三种在用结构，按风险排序：

**A. 片名 + 未闭合钩子**（最稳，新手从这里开始）
```
《银牌的眼泪》｜最痛的，不是失败，是"差一点"
《剃刀》每一个也许都要付钱：0.8⁵ = 33%
《余波》| 吵架后的沉默，会传多远？
```
规律：书名号给"作品感"，分隔符后必须是一个**疑问**或**算式**，不是陈述。

**B. 权威前缀 + 知识缺口**（热点期用）
```
今年诺奖颁给了"大脑的开关"：光遗传学到底是什么
2026诺贝尔物理学奖，冰立方中微子
什么是37法则？
```
"诺奖/2026/到底"是信任状，"××法则"是缺口。

**C. 第二人称断言**（方差最大，慎用）
```
看懂了熵增，就原谅了生活所有的力不从心
「我爱你」说到第 1000 遍，信息量几乎为零
```
一旦观众不认领这个指控就划走。

标题长度无影响（实测与播放相关性 −0.02），**结构比字数重要**。

## 六、埋点设计

每条片子埋一个可复读钩子。判据：**≤ 4 字 + 是个具象的东西 + 有归属感**。

| 埋点 | 观众反应 |
|---|---|
| 画面出现 B 站 logo / "哔哩哔哩" | 402 条复读 |
| 冰立方 → 昵称"冰冰" | 61 条 |
| 颜文字 ` <ºº> ` 鱼 | 32 条复读 |
| 日语「愛してる」 | 20 条复读 |
| 结尾"致每一个想太多的人" | 39 条"谢谢" |

做法：把概念里最长的那串名词**改成一个两字昵称**（中微子→冰冰、冰立方→冰冰），观众会替它取名字并复读。
