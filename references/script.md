# 脚本：六幕模板与十二种句型

## 一、节奏基准（实测）

| 指标 | 值 |
|---|---|
| 总时长 | 162–164 秒 |
| 句数 | 28–32 句 |
| 每句停留 | 4–6 秒（整句淡入，非打字机） |
| 平均句长 | 12–16 字 |
| 全片字数 | 450–600 字 |
| 语速 | 160–220 字/分钟（比常规知识区慢 15%） |
| 停顿 | 句间留 0.4–0.8 秒，破折号处额外 0.3 秒 |

慢，是这套片的底层质感。快起来就变成信息流，不是"放映室"。

## 二、六幕逐句模板

### ① 悖论开场（0–15s，4–5 句）

目标：给出一个**说不通**的事实，不解释。

三种起手式：

**A. 对比句**（最强）
```
领奖台上，第二名笑不出来。
第三名，却笑得像赢了。
```

**B. 第二人称场景**（代入最快）
```
他三个小时，没回消息。
你的脑子，已经替他想好了一百种解释。
而且——每一种，都说得通。
```

**C. 奇观 + 量级**
```
13 亿年前，两个黑洞撞在了一起。
整个碰撞，只有 0.2 秒。
它掀起的涟漪，2015 年才传到地球。
```

★ 三种起手式都要在 15 秒内落一个**数字**或**反差**。数字优先。

### ② 实验 / 史料（15–55s，8–10 句）

目标：用真实研究建立信任，把观众钉在椅子上。

必须有：**年份 + 人名/机构 + 一个具体数字 + 一个操作细节**。

```
1992 年，心理学家关掉声音、遮住名次——
请一群不看比赛的人，只看脸，给他们打分。
1 分是痛苦，10 分是狂喜。
分数更低的那个——是银牌。
```

「关掉声音、遮住名次」这种**操作细节**是信任的关键。观众相信的是实验怎么做，不是结论。

### ③ 命名（55–85s，6–8 句）

目标：给刚才的现象一个名字。名字一出现，观众获得掌控感。

三步：
1. **拟人化比喻**（先给形象）
2. **学术名**（再给正式名）
3. **分两个方向**（给结构）

```
大脑里，有一台停不下来的「如果机器」。
银牌的机器在算：再快一点，金牌就是我的。
铜牌的机器在算：再慢一点，我就两手空空。
...
心理学把这两种"如果"，分成两个方向。
往上想：本可以更好——叫上行反事实。
往下想：本可能更糟——叫下行反事实。
```

★ 名字要能被观众**当场复述**。"如果机器""差距机器""上行反事实"都合格；"反事实思维的理论框架"不合格。

### ④ 私人化（85–115s，5–7 句）

目标：从实验室切回观众。

★ 铁律：**三件具象小事并列，零形容词。**

```
差 3 秒没赶上的地铁，
差 1 分的分数线，
打好了、又删掉的那句话。
还有那个，差一点就在一起的人。
我们记住它们，比记住真正的失败还要久。
```

不要写"那些遗憾的时刻总是让人难以释怀"——一个形容词都不要。

### ⑤ 反转（115–145s，5–7 句）

目标：重新评价这个"缺陷"——它是功能，不是 bug。

固定起手式：**「但先别急着同情 ××。」**

```
但先别急着同情银牌。
让银牌痛的那台机器，也是让人变强的那台。
心理学家发现：总想着"本可以更好"的人，
当下更难受，下一次却做得更好。
没有哪只动物，会为 0.01 秒失眠。
```

「没有哪只动物，会为 ×× 失眠」是万能锚句：把人类痛苦限定在人类范围内，反而构成安慰。

### ⑥ 落款（145–164s，3–5 句）

目标：**升格观众**，不是总结知识点。

```
只有能想象另一种可能的大脑，
才会在下一次，把那 0.01 秒追回来。
```

常见落款句式：
- 「致所有还在观察期的人。」
- 「致每一个，想太多的人。」
- 「先伸出手，但别忘了，你有牙。」
- 「速度，是红皇后给的。方向，是你自己的。」
- 「所以，别怕你们不一样。」

★ 结构：**前半句归因于外部规律，后半句把主动权还给观众。** 只总结知识点的结尾，等于把片子降级成课件。

## 三、十二种可复用句型

| # | 句型 | 例 |
|---|---|---|
| 1 | 精确到荒谬的数字 | 「0.018 秒」「11,794,907,514 个神经元」 |
| 2 | 短句 + 破折号停顿 | 「而且——每一种，都说得通。」 |
| 3 | 给现象起名 | 「如果机器」「差距机器」 |
| 4 | 抽象物拟人化 | 「银牌的机器在算：再快一点，金牌就是我的。」 |
| 5 | 先共情再纠正 | 「你不是不理性，你只是只有一次人生。」 |
| 6 | 生物学锚点 | 「没有哪只动物，会为 0.01 秒失眠。」 |
| 7 | 三件具象小事并列 | 见第④幕 |
| 8 | 反转起手式 | 「但先别急着同情…」「可真实世界里有误会…」 |
| 9 | 结尾升格观众 | 「致每一个，想太多的人。」 |
| 10 | 原文/拉丁文点缀 | 「Pluribus non ponenda sine necessitate」 |
| 11 | 主动承认局限 | 「它读不了心，也遥控不了任何人。」 |
| 12 | 把观众拉成共犯 | 「到底，该信哪一个？」 |

第 11 条（承认局限）很少人用，但它是**信任杠杆**：主动否定一个夸张想象，观众会相信你说的其他一切。

## 四、完整范例（《银牌的眼泪》逐句还原）

```
① 悖论开场
领奖台上，第二名笑不出来。
第三名，却笑得像赢了。

② 实验/史料
1992 年，心理学家关掉声音、遮住名次——
请一群不看比赛的人，只看脸，给他们打分。
1 分是痛苦，10 分是狂喜。
分数更低的那个——是银牌。
而铜牌和第四名之间——也只差 0.01 秒。
同样的 0.01 秒，
一个离金牌那么近，一个离出局那么近。

③ 命名
大脑里，有一台停不下来的「如果机器」。
银牌的机器在算：再快一点，金牌就是我的。
铜牌的机器在算：再慢一点，我就两手空空。
研究者翻看赛后采访：银牌嘴里，更多是"差一点"；
铜牌嘴里，更多是"至少"。
心理学把这两种"如果"，分成两个方向。
往上想：本可以更好——叫上行反事实。
往下想：本可能更糟——叫下行反事实。

④ 私人化
（那些具体的小事——地铁、分数线、删掉的话）
打好了、又删掉的那句话。
还有那个，差一点就在一起的人。
我们记住它们，比记住真正的失败还要久。

⑤ 反转
但先别急着同情银牌。
让银牌痛的那台机器，也是让人变强的那台。
心理学家发现：总想着"本可以更好"的人，
当下更难受，下一次却做得更好。
没有哪只动物，会为 0.01 秒失眠。

⑥ 落款
只有能想象另一种可能的大脑，
才会在下一次，把那 0.01 秒追回来。
```

## 五、反模式

| 反模式 | 症状 | 改法 |
|---|---|---|
| 形容词轰炸 | "那种深深的、难以言说的失落感" | 换成三个具体动作 |
| 提前解释 | 第 3 句就开始下定义 | 前 15 秒只给事实，不给结论 |
| 概念先行 | 先说"今天我们讲反事实思维" | 先给现象，概念留到第 55 秒 |
| 结尾总结 | "所以，反事实思维告诉我们…" | 删掉"所以"，改成"致…" |
| 假深刻 | "人生就是一场修行" | 换成可验证的物理事实 |
| 数据堆砌 | 连续三个研究、五组数据 | 一组数据 + 一个操作细节，够了 |
| 自嗨术语 | 未加解释的专业名词连用 | 每个术语出现前，先给一个画面 |
