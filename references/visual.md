# 视觉：暗房、展品、染色字幕

## 一、曝光（最容易被忽略、最决定质感）

实测 4 条视频、约 300 万像素采样：

| 指标 | 实测值 | 目标 |
|---|---|---|
| 平均亮度 | 21.5 / 255 | ≤ 25 |
| 中位亮度 | 12 | ≤ 15 |
| 亮度 < 20 的像素 | **70.2%** | ≥ 65% |
| 亮度 > 200 的像素 | **0.47%** | ≤ 1% |

**七成画面在近黑里，高光不到千分之五。**

这不是"暗色主题"，是**打光策略**：整个画面像一间关灯的展厅，只有展品被一束光打亮。任何平均亮度超过 40 的画面都会立刻掉档。

## 二、色板

| 用途 | 色值 | 实测占比 |
|---|---|---|
| 底 | `#0A0C10` → `#101010` | 73% |
| 深蓝紫（纵深/信息层） | `#101030` | 9.9% |
| 正文白（非纯白） | `#E4E4E5` | 0.36% |
| 琥珀金（情绪焦点） | `#C9A227` / `#D9AE55`（均值 `#AD9265`） | 0.89% |
| 冷蓝（数据/仪器） | `#537FAA` | 0.28% |

**暖色像素是冷色的 3.2 倍。**

规则：**冷色承担信息，暖色承担情绪。**

- 冷蓝 `#537FAA`：网格、坐标轴、刻度、连接线、注释
- 琥珀金 `#C9A227`：奖牌、奖杯、光斑、字幕关键词、结尾暖光
- 全片暖色只出现在 **3–5 处**，每出现一次就是一个情绪爆点。用多了就不值钱。

## 三、字幕

| 项 | 规范 |
|---|---|
| 位置 | 底部居中，基线在画面 91–96% 高度 |
| 行数 | 单行优先，最多两行 |
| 字号 | 44–48px @ 1080p |
| 字重 | 300–400（细体，**不要粗体**） |
| 颜色 | `#EDEDEB`；关键词 `#C9A227` |
| 描边/阴影/背景条 | **一律不要** |
| 出现方式 | 整句淡入（0.25s），停留 4–6 秒，整句淡出 |
| 打字机效果 | 不用 |

### 关键词染色（核心技法）

**每句只染一个词**，且必须是这句的信息焦点：

| 原句 | 染色词 |
|---|---|
| 而铜牌和第四名之间——也**只差 0.01 秒** | 只差 0.01 秒 |
| 大脑里，有一台停不下来的「**如果机器**」 | 如果机器 |
| 让银牌痛的那台机器，**也是让人变强的那台** | 也是…那台 |
| 先伸出手，但别忘了，**你有牙** | 你有牙 |

作用：观众的视线被强制引导到焦点词，等于给文案加了一层隐形排版。染两个词就失效，染零个词就是白开水。

### 画面内文字与旁白分离

- **画面内**：英文/术语/数据小字（`DEPARTURES`、`AGONY 1—10 ECSTASY`、`loss`、`0.018s`），字号小，可读性放第二位
- **画面底部**：中文旁白字幕，字号大，唯一必读层

这种双层结构制造"科学仪器"的真实感。

## 四、构图与镜头

| 项 | 规范 |
|---|---|
| 平均镜头长度 | **16–40 秒**（实测 4–10 个切点 / 164 秒） |
| 切的方式 | 硬切或黑场过渡，**不用花哨转场** |
| 画面主体 | 单一主体居中，四周大量留黑 |
| 运镜 | 缓推、缓移、轨道环绕、粒子流动 |
| 每镜内部 | 必须**每一秒都在变**（否则 16 秒的镜头会死） |

★ 这是整套风格最反直觉的地方：**它不是快剪视频，是"慢镜头 + 持续运动"**。快手法的代价是画面必须自己会动——粒子、曲线生长、光斑推移、镜头缓推，四选一，不能停。

### 运动量指标（可量化自检）

用相邻帧灰度差（480×270 缩图）衡量"动感"：

| 成片类型 | 平均帧差 |
|---|---|
| 静帧轮播 / 图卡视频 | 0.09 |
| **本条风格目标** | **≥ 0.5** |
| 参考片《余波》 | 3.32（高饱和、满屏运动） |

低于 0.3 一定被说"没有动感"。主要运动量来源排序：

1. **透视地面网格**（横线向脚下滚 + 射线从消失点散开）——覆盖面积大，推帧差最有效
2. 全片一条连续的镜头曲线（1.00 → 1.16），每 6–8 秒一个呼吸，**不按幕重置**，所以永远没有静止时刻
3. 浮尘粒子（三层视差）——覆盖面积小，单独用推不动帧差
4. 冲击波环——要大而淡（r 240→1500，alpha ≈ .15），小了像随手画的圈

帧率用 60fps：镜头缓推在 30fps 下会抖。

## 五、画面元素类型（无实拍）

全部是概念可视化 CG，六大类：

1. **展品式静物**：领奖台、奖杯、奖牌、跨栏——打光如博物馆
2. **科学仪器 UI**：刻度尺、坐标轴、航班表、量表、显微镜视野
3. **数据可视化**：神经网络图、拟合曲线、轨道图、粒子场
4. **解剖/生物**：小鼠、神经元、藻类、脑区标注
5. **天象/地理**：黑洞、引力波涟漪、行星轨道、风带环流
6. **排版画面**：单个大字（「意外」「差一点」「至少」）+ 极简背景

第 6 类很重要：**纯文字画面是最便宜的高光时刻**，一句话占满屏幕，黑底白字/金字，用来做停顿和强调。

## 六、固定动作

1. **左上角常驻品牌标识**：白色细体、低透明度，全片不消失
2. **结尾转暖**：最后 15–25 秒从冷黑转向暖色（日出、沙丘、暖光晕），完成情绪释放
3. **落款字幕**：最后一句配居中大字，可截图
4. **埋点画面**：在 60–120 秒之间，插入一个可被弹幕复读的具象元素（平台 logo、可爱昵称形象、颜文字）

## 七、代码渲染对接

用 canvas/three.js 渲染时，把上述规范转成常量：

```js
const LOOK = {
  bg:        '#0A0C10',
  bgLift:    '#101030',   // 纵深渐变上沿
  text:      '#E4E4E5',
  gold:      '#C9A227',
  cold:      '#537FAA',
  vignette:  0.55,        // 暗角强度
  grain:     0.035,       // 颗粒
  subtitle:  { y: 0.935, size: 46, weight: 300, tracking: 0.04 },
  maxHighlightArea: 0.01, // 高光面积上限
  minDarkRatio: 0.65,     // 暗部占比下限
};
```

自检脚本：抽 12 帧算亮度直方图，暗部 < 65% 或高光 > 1% 就报警。
